# Git، GitHub و کار تیمی

## مباحث
Repository، Commit، Branch، Merge، Pull Request، Code Review، Conflict و Release Tag.

## جریان پیشنهادی
`issue → branch → commit → test → pull request → review → merge`

## اصول Commit
Commit کوچک، مستقل و دارای پیام روشن باشد. Secret، فایل build و تنظیمات شخصی IDE نباید Commit شوند.

## تمرین
برای یک قابلیت فرضی سه Commit منطقی و یک Pull Request description طراحی کنید.
