# آمادگی مصاحبه Java

## Java Core
تفاوت JDK/JRE/JVM، equals/hashCode، String immutability، final، static، Exception، Collections و Generics.

## OOP
Encapsulation، Inheritance، Composition، Polymorphism، Interface و SOLID.

Stack/Heap، GC، Class Loading و Memory Leakهای منطقی.

## Backend
HTTP، REST، Transaction، SQL Index، JPA، Spring DI، Security و Testing.
