# Recursion، Tree و Graph

## Recursion
هر تابع بازگشتی باید Base Case داشته باشد.

```java
static long factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

## Tree
Node، Root، Leaf، Depth، BST و Traversal.

## Graph
Vertex، Edge، Directed/Undirected، BFS و DFS.

## تمرین
DFS و BFS را روی یک Graph کوچک پیاده‌سازی و ترتیب بازدید را مقایسه کنید.
