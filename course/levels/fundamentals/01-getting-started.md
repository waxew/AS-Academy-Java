# 01 — شروع Java

## هدف
شناخت Java، JVM، JRE و JDK و درک مسیر تبدیل سورس به Bytecode.

## مباحث
- Java چیست و چه کاربردهایی دارد
- تفاوت Java با JavaScript، Kotlin و C#
- JVM، JRE، JDK
- Source Code و Bytecode
- فایل‌های `.java` و `.class`

## مثال
```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java!");
    }
}
```

## تمرین
برنامه‌ای بنویسید که نام، هدف آموزشی و نسخه Java را چاپ کند.

## خروجی یادگیری
هنرجو می‌تواند چرخه Compile/Run را توضیح دهد و اولین برنامه را اجرا کند.
