# پروژه آمادگی استخدام

یک REST API واقعی انتخاب و از صفر پیاده‌سازی کنید.

## الزامات
Java، Spring Boot، PostgreSQL، JPA، Validation، Authentication، Authorization، Unit Test، Integration Test، Docker، OpenAPI و README کامل.

## دفاع پروژه
