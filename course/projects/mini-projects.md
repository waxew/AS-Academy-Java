# پروژه‌های مرحله‌ای Java

## مبانی — Grade Analyzer
ورودی نمرات، محاسبه min/max/average، تعیین قبولی و گزارش Console.

## مقدماتی — Invoice Manager
مدل‌های Customer، Product، Invoice و InvoiceItem با OOP، Collection و Exception اختصاصی.

## پیشرفته — Student JDBC
CRUD دانشجو با JDBC، PreparedStatement، Transaction و Repository Pattern.

## تخصصی — Learning REST API
Spring Boot API شامل Course، Lesson، Student، Enrollment، Validation، JPA و Security.

## پروژه نهایی — Academy Store API
پروژه یکپارچه برای تمرین معماری Backend. این پروژه ابزار آموزش مباحث تخصصی است و هدف اصلی Course نیست.
