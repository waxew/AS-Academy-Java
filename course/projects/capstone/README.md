# Capstone — Academy Store API

## دامنه‌ها
- Auth: Register, Login, JWT, Roles
- Users: Admin, Customer, Staff
- Catalog: Category, Product, Search
- Inventory: Stock movements
- Commerce: Cart, Order, Invoice, Payment
- Platform: Validation, Logging, Error handling, Security

## Stack
Java، Spring Boot، Spring Security، JPA/Hibernate، PostgreSQL، JUnit، Mockito، Docker، OpenAPI.

- API قابل اجرا

- تست‌های کلیدی
- عدم ذخیره Secret در Git
- Dockerfile
- Health endpoint
- OpenAPI docs
