# Academy Store API

پروژه نهایی مسیر Java Professional.

## وضعیت فعلی
Skeleton اجرایی Spring Boot شامل Product Entity، Repository، Service، Controller، Validation، PostgreSQL config و Dockerfile.

## مراحل توسعه بعدی داخل دوره
1. Category
2. Inventory
3. User / Role
4. Register / Login
5. Spring Security
6. JWT
7. Cart
8. Order / OrderItem
9. Invoice
10. Payment abstraction
11. Global Exception Handler
12. Pagination / Search
13. Unit Tests
14. Integration Tests
15. OpenAPI
16. Docker Compose
17. CI
18. Production profile

## اجرا
```bash
mvn spring-boot:run
```

## Endpoint اولیه
```text
GET  /api/products
POST /api/products
```
