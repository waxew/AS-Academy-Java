# Student JDBC

پروژه پایان سطح پیشرفته Java.

## هدف
تمرین JDBC، SQL، PreparedStatement، Resource Management و Persistence.

## الزامات
- ساخت جدول در اولین اجرا
- Create Student
- Read/List Students
- استفاده از PreparedStatement
- مدیریت Connection/Statement/ResultSet با try-with-resources

## معیار قبولی
- داده بعد از بسته‌شدن برنامه باقی بماند.
- Email تکراری کنترل شود.
- SQL با String concatenation ورودی کاربر ساخته نشود.
- خطاهای دیتابیس به شکل قابل فهم مدیریت شوند.

## مرحله تکمیلی
Update، Delete، Search، Transaction و Repository Pattern کامل را اضافه کنید.
