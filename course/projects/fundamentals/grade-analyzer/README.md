# Grade Analyzer

پروژه پایان سطح مبانی Java.

## هدف
تمرین Array، Loop، Method، شرط و محاسبات عددی.

## صورت مسئله
برنامه باید مجموعه‌ای از نمرات را دریافت و موارد زیر را محاسبه کند:
- کمترین نمره
- بیشترین نمره
- میانگین
- تعداد قبول‌شده‌ها

## معیار قبولی
- برنامه بدون خطا اجرا شود.
- منطق محاسبه در Methodهای جدا باشد.
- روی آرایه خالی تصمیم مشخص داشته باشد.
- حداقل سه ورودی متفاوت تست شود.

## مرحله تکمیلی
ورودی را با `Scanner` از کاربر بگیرید و تعداد نمرات را پویا کنید.
