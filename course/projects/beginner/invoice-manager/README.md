# Invoice Manager

پروژه پایان سطح مقدماتی Java.

## هدف
تمرین OOP، Record، Encapsulation، Collection و Business Rule.

## الزامات
- Product دارای شناسه، نام و قیمت معتبر باشد.
- InvoiceItem تعداد مثبت داشته باشد.
- Invoice چند قلم را نگهداری کند.
- مبلغ هر قلم و مبلغ کل محاسبه شود.
- قیمت‌ها در خروجی خوانا نمایش داده شوند.

## معیار قبولی
- ورودی نامعتبر Reject شود.
- Collection داخلی مستقیماً قابل تغییر از بیرون نباشد.
- محاسبه مبلغ در Model مناسب قرار گیرد.
- حداقل یک فاکتور چندقلمی اجرا شود.

## مرحله تکمیلی
Customer، Discount، Tax، Status و ذخیره فایل را اضافه کنید.
