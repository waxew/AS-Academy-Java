# پروژه — Algorithm Visual Lab

یک برنامه Console آموزشی بسازید که Array تولید کند و الگوریتم‌های Linear Search، Binary Search، Bubble Sort، Merge Sort و Quick Sort را اجرا کند.

برای هر اجرا نمایش دهید:
- ورودی
- خروجی
- تعداد مقایسه‌ها
- زمان تقریبی اجرا
- Big O نظری

## مرحله تکمیلی
Tree و Graph اضافه کنید و Traversalهای BFS/DFS را نمایش دهید.
