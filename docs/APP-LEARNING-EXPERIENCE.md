# تجربه یادگیری Java در برنامه

هدف اصلی این Course Package آموزش Java است.

## صفحه دوره
کاربر چهار سطح مبانی، مقدماتی، پیشرفته و تخصصی را می‌بیند. هر سطح درصد پیشرفت و فصل‌های خود را از Core دریافت می‌کند.

## صفحه درس
ترتیب پیشنهادی: هدف → توضیح → Code → Output → نکته → تمرین → Quiz کوتاه → ادامه.

## پیشرفت
Progress Engine متعلق به AS-Academy-Core است. Course فقط Stable ID و ترتیب محتوا را ارائه می‌کند.

## پایان سطح
کاربر Quiz سطح و Mini Project را انجام می‌دهد. حدنصاب پیشنهادی Quiz برابر 70٪ است.

## قابلیت‌های مورد انتظار
Search، Bookmark، Offline Content، Progress، Quiz، Exercise، Glossary و Project Tracking همگی از Core استفاده می‌شوند.
