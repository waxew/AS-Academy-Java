# انتشار محتوای Java

## 1.3.0
- تثبیت مسیر 38 فصلی و انتقال Capstone به انتهای مسیر.
- تعمیق Generics/Streams، Concurrency، JVM، JDBC و Testing.
- تعمیق Algorithms، Data Structures، Recursion/Graph و Dynamic Programming.
- تعمیق Reflection/Annotation، HTTP/JSON، Maven/Gradle/Logging و Design Patterns.
- تعمیق Spring Core، Spring Boot، REST، JPA/Hibernate و Security/JWT.
- افزایش بانک تمرین به 165 تمرین مرحله‌بندی‌شده.
- هماهنگ‌سازی learning milestones با ترتیب جدید.
- اضافه‌شدن `branding.json` و تکمیل Manifest مطابق قرارداد جاری AS-Academy-Core.
- همگام‌سازی metadata نسخه محتوا و curriculum روی 1.3.0.
