# اتصال به AS Academy Core

این ریپو Course Repository است و منطق مشترک اپ را تکرار نمی‌کند.

## از Core استفاده می‌شود
- Navigation و App Shell
- Design System
- Room/Database
- Content Engine و Import/Update
- Progress Engine
- Quiz Engine
- Exercise Engine
- Project Engine
- Search
- Bookmark
- Glossary Engine
- Profile / Drawer
- Settings
- Achievement
- Backup
- Update Engine
- Code Runner Framework
- Course Schema و Validation

## در این ریپو باقی می‌ماند
- درس‌های Java
- مثال‌های Java
- تمرین‌ها و آزمون‌ها
- پروژه‌ها
- واژه‌نامه Java
- Branding و Metadata دوره
- Capabilityهای منحصربه‌فرد Java

## قانون
هر قابلیت قابل استفاده در بیش از یک دوره باید ابتدا در `AS-Academy-Core` پیاده‌سازی شود.
